# S120 — 반응 라벨 체계(Taxonomy) 유도부

발명내용 설명서 5.(2)단계 / [도면 1] S120에 대응한다.

## 단계 내용

정제된 코퍼스를 임베딩 모델로 벡터화하고 클러스터링을 수행한 뒤, 언어모델로 각
클러스터의 의미를 명명하고 인간 큐레이션을 거쳐 반응 라벨 체계를 확정한다.
분류 불가 텍스트를 수용하는 노이즈 라벨을 포함하여 K개 라벨을 정의한다 (실시예: 12개).

## 산출물

- `label_descriptions.json` — 확정된 12개 라벨의 정의·키워드

확정된 라벨 체계는 `S130_이중라벨링_분류기학습부/model_training_script/config.py`
의 `LABELS` 에 코드로 고정되어 이후 전 단계에서 동일하게 사용된다.

## 구현 현황

**임베딩·클러스터링·LLM 명명 코드는 이 저장소에 포함되어 있지 않다.**
12개 라벨은 위 산출물과 config.py 에 결과로만 남아 있으며, 유도 과정을 재현하는
스크립트는 미구현 상태다. 라벨 체계를 다른 아티스트군으로 재유도하려면 이 단계의
구현이 선행되어야 하며, 그 경우 설명서 [도면 1]의 조건부 피드백 경로
(파라미터 변경 시 S120부터 자동 재수행)가 이 디렉터리에서 시작된다.
