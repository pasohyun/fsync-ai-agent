# F-Sync 환절기 Gap 분석 대시보드 — 최종 확정본

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```
압축을 어디에 풀어도 동작합니다 (app.py가 자기 위치 기준 상대경로로 데이터를 찾음).

## 화면 구성
1. 헤드라인 카드 2개 — 가장 아쉬운 포인트 / 기대 이상의 호응 (실제 댓글 인용 포함)
2. 다음 컴백을 위한 제안
3. 팬들이 많이 쓴 표현 — 클릭형, 강조 3종(청량 여름·밴드 정체성·위로 공감) + 자생 1종(연주 악기)만 포함.
   비강조 라벨(음악성, 장기 팬덤 등)은 의도적으로 제외 — "의도한 메시지에 대한 반응만" 보여주기 위함.
4. 라벨별 반응 추이 — 다중 선택 토글로 여러 라벨을 겹쳐서 비교. 프로모션 일정(PROMO_EVENTS)이 점선으로 표시됨.
5. 같은 라벨 · 컴백 단계별 비교 — 티저/뮤직비디오/음악방송/부가 콘텐츠 4단계.
   video_title 문자열 패턴으로 분류 (classify_stage 함수) — 메타필드보다 신뢰도 높음.

## LLM 연동 상태
이 화면의 모든 텍스트(제안 문구, 캡션 등)는 현재 정규식·규칙 기반 자동 생성입니다.
LLM은 연결되어 있지 않으며, 현재 화면 구성에는 필수가 아닙니다.
(이미 계산된 lift·verdict를 보여주거나 단순 비교/정렬하는 수준이라 LLM 없이도 완전히 작동함)

향후 LLM을 붙인다면:
- "다음 컴백을 위한 제안" 문구를 데이터 패턴 종합 기반 동적 생성으로 고도화
- 워드클라우드 표현을 댓글 빈도 1위 그대로 쓰는 대신, 후보군 중 가장 자연스러운 것을 LLM이 선별
- 마케팅 채널별(SNS/쇼츠/굿즈) 신규 카피 창작 패널 추가
관련 코드 골격은 별도 파일(llm_action_suggestion.py 등, 이전 핸드오프 패키지 참고)에 있음.

## 디자인 안내 (Claude Code 작업용)
이 코드는 데이터 로직과 인터랙션 구조에 집중했고, 디자인 토큰은 최소한만 잡아뒀습니다.
- `VERDICT_COLOR`, `SERIES_COLOR` 딕셔너리에서 색상 일괄 교체 가능
- 밴드/FNC 톤(어두운 톤 + 코랄·틸 포인트 등)으로 자유롭게 다듬어주세요
- Streamlit 네이티브 컴포넌트(st.button, st.container 등) 기반이라 커스텀 CSS 적용 시
  st.markdown(unsafe_allow_html=True)로 확장 가능

## 워드클라우드 클릭 구현 방식 (중요 — Claude Code에서 확인 필요)
"팬들이 많이 쓴 표현" 섹션은 진짜 워드클라우드처럼 보이면서도 클릭 가능해야 한다는 요구사항 때문에,
다음 방식으로 구현했습니다:

1. 각 표현을 `st.button`으로 만들되, 버튼 테두리/배경을 투명하게 하고 `font-size`를 라벨의
   히트 수(`n_hits`)에 비례하게 CSS로 덮어써서 시각적으로 워드클라우드처럼 보이게 함
2. CSS 스코프는 `st.container(key="wordcloud_grid")`가 자동 생성하는 `.st-key-wordcloud_grid`
   클래스 + `nth-of-type` 선택자로 각 버튼을 정확히 타겟팅

**알려진 위험**: 이 방식은 Streamlit의 내부 DOM 구조(`data-testid="column"` 등)에 의존합니다.
Streamlit 버전이 크게 바뀌면 CSS가 깨질 수 있습니다 (현재 1.58.0 기준 작성·검증, `st.container(key=...)`는
1.x 비교적 최신 버전에서만 지원되므로 구버전이면 `pip install --upgrade streamlit` 필요).
만약 클릭이 안 되거나 워드클라우드 모양이 깨진다면:
- 브라우저 개발자도구로 실제 DOM 구조(`data-testid` 값)를 확인하고 CSS 선택자를 맞춰주세요
- 더 견고한 대안: `streamlit.components.v1.html`로 진짜 HTML/JS 워드클라우드를 만들고
  `postMessage`로 클릭 이벤트를 메인 앱에 전달하는 방식 (더 복잡하지만 DOM 구조 변경에 안전)
